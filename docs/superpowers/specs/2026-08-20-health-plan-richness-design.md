# 健康方案内容增强设计

## 目标

将健康方案中的“AI药理科普”和“AI健康管理方案”从概述式文本升级为可操作、可审核的个体化内容，同时保持既有患者覆盖、药物白名单和医疗合规边界。

## AI药理科普

每种审核药物单独成段并以原药名开头。每段同时包含通俗药理机制、本患者方案中的用途、审核处方中的执行要点，以及药物特异性的风险与监测。手术或器械存在时另行说明。不得用通用免责声明代替实质科普，不得引入审核清单之外的药物。

## AI健康管理方案

输出4～6个编号模块，覆盖病情或术后监测、用药执行与安全、活动康复、饮食营养、复诊或异常升级。模块应说明动作、频次或时机、观察目标，以及目标未达成时的处理。至少包含两个建议频次、建议目标或行动阈值。

数值只能作为面向未来的建议目标或行动阈值，不得描述为患者已经测得的基线、检查结果或疗效趋势。依赖检查、器官功能、合并症或医生个体化设定的目标不得擅自推定。

## 校验与测试

构建程序拒绝每种药物未单独成段、缺少机制/执行/风险要素的药理文本；拒绝少于4个管理模块、缺少核心管理领域、缺少量化指导或异常处理的健康方案。新增回归测试证明旧的“一句话药理 + 三条概述”无法通过，并保留完整工作簿回归测试。
