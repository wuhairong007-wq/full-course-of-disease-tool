# 阶段1疾病适配给药途径设计

## 目标

修复患者明细生成中“给药途径仅按剂型默认”的风险，使 AI 必须结合疾病部位、治疗目标、药品剂型及已审核药品允许途径进行动态判断。不得把某个疾病永久绑定到单一给药途径。

## 方案

在阶段1临床规则中增加“疾病—治疗目标—给药途径”判断层：

1. 先识别药物承担的治疗作用（例如气道廓清、局部眼科治疗、软组织局部处理、全身抗感染或镇痛）。
2. 再结合疾病解剖部位、治疗场景、患者年龄/过敏史和药品说明书或审核数据允许的途径，选择适用途径。
3. 图片示例（呼吸系统可能使用雾化吸入、眼科可能使用眼科局部用药、软组织损伤可能使用局部注射或外用）仅作为推理线索，不建立疾病到单一途径的硬编码映射。
4. 若当前途径与治疗目标冲突，必须重新生成完整处方候选：规格、每次用量、途径、频次、时机、疗程和专项警示一起重建；禁止只替换途径。
5. 若无法确认安全且适用的途径，停止生成并报告患者、药物和冲突原因，禁止默认“肌内注射”。

## 校验与测试

- 保留现有剂型结构校验，确保选择的途径是该剂型允许的途径。
- 新增可审计的路线判断检查：气道疾病示例不能在缺少依据时沿用肌内注射；其他疾病不得被强制改成雾化吸入。
- 回归场景至少覆盖：支气管扩张/鼻窦炎等气道疾病、眼科疾病、软组织损伤，以及仍合理使用肌内注射的非气道疾病。
- 测试确认同一药物在不同治疗目标下可以得到不同但均有依据的途径，且等效替换后整条处方参数同步更新。

## 不改变的约束

- 不修改源工作簿，不改变患者顺序、药物治疗作用数量或 3–5 项用药范围。
- 不用疾病名称的简单字符串匹配替代临床判断。
- 不引入未审核药物、未支持剂量、虚构检查结果或缺失资料占位文案。
