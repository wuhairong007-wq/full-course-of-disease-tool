# 患者提供处方字段文案与旧列名兼容

患者明细当前输出表头中的 `处方清单` 改为 `患者提供处方`。新列名适用于 16 列当前表头，以及带有状态列的 17/18 列兼容表头和相关引用文档。

下游阶段 2～4 读取患者明细时，同时接受 `患者提供处方` 和旧列名 `处方清单`，并继续映射到内部字段 `prescriptionList`。同一输入不得同时出现两个列名；列顺序、列数、`userid` 顺序、工作簿布局和生成内容规则保持不变。旧列名只作为输入兼容别名，不再作为新模板或新生成工作簿的输出列名。

所有依赖患者明细表头的解析器、构建器、测试和技能文档必须使用同一列名契约。模板资产的患者明细表头更新为 `患者提供处方`，并在回读检查中验证新表头。
