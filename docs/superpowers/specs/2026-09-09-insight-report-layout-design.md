# 洞察报告版式增强设计

## 目标

调整 `generating-patient-full-course-data` 的洞察报告生成流程，使报告包含参考文档式封面、自动目录、正文页码，并将症状雷达图改为六维评分分布图样式，同时删除图表下方的解释段。

## 设计

- 封面作为独立第一页，包含报告标题和六行信息表：委托方、服务商、产品、服务地区、服务周期、报告日期。委托方和服务商通过洞察报告请求中的可选参数提供；缺失时留空，不读取参考文档中的示例值。服务地区从患者主表地区字段汇总，报告日期取生成月份。
- 封面后插入 Word 动态目录字段，目录范围覆盖一级、二级和三级标题，并使用点引导线和页码。正文另起一节，页码从正文第 1 页开始，封面和目录不显示页码。
- 症状六维雷达图使用 0-5 评分范围、黑色外圈、灰色同心网格、蓝色半透明多边形和数据节点，轴标签使用简短维度名称，图内标题为“六维度评分分布图”。
- 每个图表保留“图 X-X：名称”图注，移除其下方的“图表说明：……”段落；核心信息继续保留在图表清单中供内部数据追溯。
- 校验器检查封面字段、目录字段、正文页码字段、图注说明段移除和图表媒体完整性。现有九章内容、统计口径和数据对账规则保持不变。

## 输入约定

洞察报告触发语句继续要求产品、服务周期和七个 Excel 路径，并新增可选行：

```text
委托方：<名称>
服务商：<名称>
```

两项均可省略。参考文档和截图属于版式参考，不属于数据输入指令。
